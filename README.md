# PumpWatch — پایشگر، شبیه‌ساز معامله و بک‌تست پامپ رمزارزها (اندروید)

اپلیکیشن اندرویدی که قیمت/حجم رمزارزهای **رتبه ۳۰۰ تا ۶۰۰** را از CoinGecko
می‌گیرد، پامپ زودهنگام را با ترکیب چند سیگنال تشخیص می‌دهد، یک معامله
**کاملاً شبیه‌سازی‌شده** (بدون پول واقعی) با استاپ شناور باز/بسته می‌کند، و
یک ماژول بک‌تست دارد. اپ پشت یک صفحه ورود خصوصی (یوزرنیم/رمز عبور محلی، بدون
سرور) قفل است. **هیچ اتصالی به صرافی برای معامله واقعی وجود ندارد.**

> **تغییر مهم نسبت به نسخه قبلی**: اگه قبلاً یه repository ساختی و فایل‌های
> نسخه قبل رو آپلود کردی، اون نسخه یه باگ داشت (یه کتابخونه رمزنگاری قدیمی و
> ناپایدار که باعث می‌شد اپ فوری بعد از باز شدن کرش کنه — دقیقاً همون «نصب شد
> ولی هیچی نشون نداد»). این نسخه اون رو با یه روش پایدارتر جایگزین کرده و یه
> صفحه گزارش کرش هم اضافه شده. ساختار پوشه‌ها هم عوض شده (خیلی کمتر شده). به
> همین خاطر **بهتره یه repository تازه بسازی** (مثلاً با اسم `pumpwatch2`)
> به‌جای اضافه کردن این فایل‌ها روی نسخه قبلی — چون قاطی شدن ساختار قدیم و
> جدید می‌تونه باعث خطای کامپایل بشه.

---

## بخش ۱: این پروژه چیست

یک پروژهٔ کامل کد منبع Kotlin + Jetpack Compose است، نه یک فایل APK آماده.
من در محیط چت به اینترنت و ابزارهای کامپایل اندروید دسترسی ندارم، پس نمی‌توانم
خودم APK بسازم. پایین‌تر **دو روش کامل** برای تبدیل این کد به اپ نصب‌شدنی روی
گوشی توضیح داده شده — هر دو را می‌شود **فقط با گوشی**، بدون کامپیوتر، انجام داد.

## بخش ۲: چطور از روی گوشی، APK بسازیم

### روش A (پیشنهادی و مطمئن‌تر): ساخت ابری با GitHub Actions

اینجا خودِ سرورهای گیت‌هاب کد رو کامپایل می‌کنن و در آخر یه فایل APK آماده
دانلود بهت می‌دن. رایگانه و نیازی به نصب هیچ برنامه سنگینی رو گوشی نداره.

**مرحله ۱ — فایل‌ها رو از حالت فشرده خارج کن**
فایل zip که بهت دادم رو با یه اپ فایل منیجر (مثلاً «Files» یا ZArchiver) از
حالت zip خارج کن تا یه پوشه به اسم `PumpWatch` با همه فایل‌های داخلش داشته باشی.

**مرحله ۲ — ساخت اکانت گیت‌هاب**
با مرورگر گوشی برو به [github.com](https://github.com) → «Sign up» → یه
اکانت رایگان بساز (فقط ایمیل لازم داره).

**مرحله ۳ — ساخت یک Repository جدید**
بعد از ورود: دکمه «+» بالای صفحه → «New repository» →
- Repository name: مثلاً `pumpwatch`
- Public یا Private، فرقی نمی‌کنه
- تیک «Add a README file» را **نزن** (چون خودمون README داریم)
- «Create repository»

**مرحله ۴ — آپلود فایل‌های پروژه (پوشه به پوشه)**
چون فایل منیجر گوشی‌ها معمولاً اجازه نمی‌دن یه پوشه با زیرپوشه‌هاش رو یکجا
انتخاب کنی، ساختار پروژه رو تخت (کم‌پوشه) نگه داشتم — فقط ۸ تا پوشه داری که
باید جدا جدا آپلود کنی. تو صفحه repository: «Add file» → «Upload files» →
هر بار «choose your files» رو بزن، از پوشه زیر چند فایلی که همون‌جا هست رو
همزمان انتخاب کن (چند-انتخابی معمولاً تو فایل منیجرها جواب می‌ده)، و بعد از
هر دسته، پایین صفحه **Commit changes** رو بزن (می‌تونی چندبار Commit بزنی،
مشکلی نیست):

1. فایل‌های ریشه پروژه: `README.md`, `build.gradle.kts`, `gradle.properties`, `settings.gradle.kts`
2. پوشه `.github/workflows/` → فایل `build.yml`
3. پوشه `gradle/wrapper/` → فایل `gradle-wrapper.properties`
4. پوشه `app/` → `build.gradle.kts`, `proguard-rules.pro`
5. پوشه `app/src/main/` → `AndroidManifest.xml`
6. پوشه `app/src/main/java/com/pumpwatch/app/` → همه‌ی ۳۴ فایل `.kt` (همشون تو یه پوشه‌ان، همزمان انتخابشون کن)
7. پوشه `app/src/main/res/drawable/` → دو فایل xml
8. پوشه `app/src/main/res/mipmap-anydpi-v26/` → دو فایل xml
9. پوشه `app/src/main/res/values/` → دو فایل xml

نکته مهم: وقتی برای هر مرحله «Upload files» رو باز می‌کنی، آدرس بالای صفحه
باید مسیر همون پوشه رو نشون بده. اگه دیدی صفحه‌ای که باز شده مسیر درست رو
نشون نمی‌ده (مثلاً می‌خوای بری تو `app/src/main/res/drawable` ولی صفحه اصلی
repository رو نشونت می‌ده)، از داخل خودِ سایت گیت‌هاب برو تو پوشه موردنظر
(روی اسم پوشه‌ها لمس کن تا باز بشن) و از همون‌جا «Add file → Upload files»
رو بزن — اینجوری خودش مسیر رو درست تنظیم می‌کنه.

**مرحله ۵ — دیدن ساخت خودکار APK**
همین که فایل‌ها آپلود شدن، فایل `.github/workflows/build.yml` که داخل پروژه
گذاشتم خودش فعال می‌شه و گیت‌هاب شروع به ساخت APK می‌کنه. برای دیدنش:
تب «Actions» بالای صفحه repository → روی آخرین run (اسمش چیزی شبیه
«Build APK») بزن → صبر کن (معمولاً ۲ تا ۵ دقیقه) تا یه ✅ سبز بشه.

**مرحله ۶ — دانلود APK**
همون صفحه run، پایین‌تر بخش «Artifacts» → روی `PumpWatch-debug-apk` بزن تا
دانلود بشه (یه فایل zip کوچیک که خودِ APK داخلشه). از حالت zip خارجش کن، فایل
`app-debug.apk` رو پیدا کن، لمسش کن تا نصب بشه (ممکنه گوشی بپرسه «اجازه نصب از
منابع ناشناس» بدی — تأیید کن).

اگه بعداً کد رو عوض کردی و دوباره آپلود (commit) کردی، این فرآیند خودکار
دوباره اجرا می‌شه و APK جدید می‌سازه — کافیه دوباره بری تب Actions.

### روش B: کامپایل مستقیم روی خود گوشی (بدون GitHub)

اگه نمی‌خوای از گیت‌هاب استفاده کنی، اپ‌های IDE اندرویدی هست که مستقیم رو
گوشی کامپایل می‌کنن، مثل **CodeAssist - Android IDE** یا **Android IDE -
PHONE AS** (هر دو رایگان، تو Google Play). مراحل کلی:
1. اپ رو از Google Play نصب کن.
2. پوشه `PumpWatch` (از حالت zip خارج‌شده) رو داخل حافظه گوشی قرار بده.
3. داخل IDE گزینه «Open Project» یا «Import Project» رو بزن و پوشه رو انتخاب کن.
4. صبر کن وابستگی‌ها (Gradle dependencies) دانلود بشن — این به اینترنت نیاز داره.
5. گزینه Build/Compile → APK رو بزن.

⚠️ **صادقانه بگم**: این پروژه از Jetpack Compose و نسخه‌های نسبتاً جدید Kotlin/
Android Gradle Plugin استفاده می‌کنه. IDEهای روی‌گوشی معمولاً behind نسخه‌های
جدید هستن و ممکنه با بخش Compose این پروژه به مشکل بخورن یا کندتر از GitHub
Actions باشن. **روش A را توصیه می‌کنم** چون از همون ابزارهای رسمی گوگل
(Gradle واقعی) استفاده می‌کنه و احتمال خطا خیلی کمتره.

---

### روش C (اختیاری، اگه بعداً به کامپیوتر دسترسی پیدا کردی)

1. [Android Studio](https://developer.android.com/studio) رو نصب کن (رایگان).
2. پوشه `PumpWatch` رو باز کن (Open).
3. Android Studio چون فایل باینری `gradle-wrapper.jar` رو تو این پروژه پیدا
   نمی‌کنه (من نمی‌تونم فایل باینری اینجا بسازم)، یه پیام می‌ده «Gradle wrapper
   not found» یا شبیه اون — گزینه «Create Gradle Wrapper» یا «OK» رو بزن تا
   خودش بسازتش (خودکاره، نیاز به کار دستی نداره).
4. صبر کن Gradle Sync تموم بشه.
5. Build → Build Bundle(s)/APK(s) → Build APK(s).
6. فایل APK در `app/build/outputs/apk/debug/` ساخته می‌شه.

## بخش ۳: اولین اجرای اپ

اولین بار که اپ رو باز کنی، صفحه «راه‌اندازی ورود اپ» میاد — یه نام کاربری و
رمز عبور (حداقل ۶ کاراکتر) برای خودت انتخاب کن. این کاملاً محلی و روی خودِ
گوشیته (رمزنگاری‌شده با Android Keystore)، هیچ سروری درکار نیست.

⚠️ **مهم**: چون سرور نداره، اگه رمز رو فراموش کنی، تنها راه بازگشت پاک کردن
داده اپ (Clear Data) یا نصب دوباره‌ست که یعنی باید از اول یوزر/پسورد بسازی —
پس جایی امن یادداشتش کن.

بعد از ورود، از داشبورد «بروزرسانی» رو بزن تا لیست کوین‌های رتبه ۳۰۰-۶۰۰
بیاد؛ از تنظیمات می‌تونی آستانه‌ها رو عوض کنی، از «معاملات» شبیه‌سازی رو روشن
کنی، و از «بک‌تست» عملکرد گذشته استراتژی رو بسنجی.

## معماری خلاصه

- `data/remote` → ارتباط با API رایگان CoinGecko
- `data/repository/MarketRepository` → واکشی چندصفحه‌ای برای پوشش رتبه‌های موردنظر، فیلتر بر اساس `market_cap_rank`
- `domain/PumpDetector` → سه سیگنال مستقل (قیمت، شتاب حجم، مومنتوم) ترکیبی
- `domain/TradingEngine` + `data/repository/TradeRepository` → باز/بسته کردن معاملات شبیه‌سازی‌شده با استاپ شناور
- `domain/Backtester` → اجرای همان منطق روی داده‌های تاریخی
- `worker/MonitoringService` → سرویس فورگراند برای بررسی دوره‌ای
- `ui/auth` → صفحه ورود محلی صاحب اپ (بدون سرور)
- `ui/dashboard, trades, backtest, settings, detail` → صفحات اپ (همه فارسی)

## چطور تشخیص پامپ کار می‌کند

سه سیگنال هر دور بررسی محاسبه می‌شود: درصد تغییر قیمت، شتاب حجم نسبت به
میانگین اخیر، و تعداد تیک‌های صعودی پیاپی. هشدار/ورود به معامله فقط وقتی
اتفاق می‌افتد که حداقل تعداد مشخصی از این سیگنال‌ها (پیش‌فرض ۲ از ۳) همزمان
فعال شوند. بازه رتبه (پیش‌فرض ۳۰۰-۶۰۰) و همه آستانه‌ها از «تنظیمات» قابل تغییرند.

## معامله شبیه‌سازی‌شده (Paper Trading)

خاموش است مگر از صفحه «معاملات» روشنش کنی — هیچ سفارش واقعی به هیچ صرافی
ارسال نمی‌شود. ورود: وقتی یک کوین در بازه رتبه انتخابی سیگنال پامپ می‌گیرد.
خروج: **استاپ شناور** (سطح خروج فقط بالا می‌رود، هیچ‌وقت پایین نمی‌آید)، یا
**تشخیص برگشت روند مستقل** (افت ناگهانی از سقف + چند تیک نزولی پیاپی)، یا
**حد ضرر اولیه ثابت** برای وقتی بلافاصله بعد از ورود قیمت برعکس می‌شود.

## بک‌تست

از صفحه «بک‌تست»: چند کوین انتخاب کن، یک بازه (۱ تا ۹۰ روز)، و همان الگوریتم
روی داده تاریخی اجرا می‌شود. ⚠️ نسخه رایگان CoinGecko برای بازه بیش از ۱ روز
فقط داده **ساعتی** می‌دهد، پس نتیجه یک تقریب است، نه دقیق ۱۰۰٪؛ کارمزد و
اسلیپیج هم حساب نمی‌شود — فقط ابزار اولیه سنجش منطق استراتژی است، نه مشاوره مالی.

## نکات مهم قبل از هر تصمیم مهم

- **نرخ درخواست CoinGecko**: نسخه رایگان محدودیت نرخ دارد؛ برای فاصله بررسی
  خیلی کوتاه یا استفاده سنگین، به کلید API/پلن پولی نیاز پیدا می‌کنی.
- این اپ **مشاوره مالی نیست** و سیگنال‌ها/بک‌تست تضمینی برای سود ندارند.
- تاریخچه فقط در حافظه (RAM) نگه داشته می‌شود و با بستن کامل اپ از بین می‌رود؛
  برای نگهداری بلندمدت می‌شود یک دیتابیس محلی (Room) اضافه کرد.
- اتصال واقعی به صرافی (فعلاً عمداً پیاده نشده) اگر در آینده اضافه شود، کلید
  API صرافی **باید** فقط با مجوز «Enable Trading» ساخته شود — «Enable
  Withdrawals» (برداشت وجه) همیشه خاموش بماند، و «IP Whitelist» هم فعال شود.

## قدم بعدی پیشنهادی

- ذخیره‌سازی تاریخچه با Room برای بررسی روند بلندمدت‌تر و بک‌تست دقیق‌تر
- اتصال واقعی (اختیاری، در آینده) به صرافی — با رعایت الزام امنیتی بالا
